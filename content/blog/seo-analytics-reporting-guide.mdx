Data without action is noise. Here's the reporting stack that drives decisions.

## GA4 Setup

Events: scroll_90, file_download, form_start, form_submit, whatsapp_click, phone_click, booking_start, booking_complete. Enhanced measurement ON. Custom dimensions: author, category, word_count, publish_date.

## Search Console Integration

Link GA4 + GSC. Query-level data in GA4. Monitor: impressions, clicks, CTR, average position. Alert on >20% drops.

## Custom SEO Dashboard (Looker Studio)

**Traffic Quality**: organic sessions, engaged sessions, engagement rate, pages/session, avg session duration. **Conversions**: form submits, WhatsApp clicks, calls, bookings — by landing page, source, keyword cluster. **Technical**: Core Web Vitals (CrUX), crawl stats, index coverage, sitemap status. **Rankings**: target keyword positions (weekly), featured snippets, local pack presence. **Content**: top landing pages, content decay (declining traffic), keyword cannibalization.

## Reporting Cadence

Weekly: traffic/conversions snapshot, anomalies. Monthly: full dashboard, keyword movement, content opportunities. Quarterly: strategy review, competitor gap, budget allocation.

## Attribution

Data-driven attribution in GA4. Assisted conversions report. First/last touch for channel mix. Offline conversion import (CRM → GA4 Measurement Protocol).

## Alerts

Traffic drop >30% day-over-day. Core Web Vitals regression. Index coverage error spike. Manual action notification. Ranking drop for top 10 keywords.

## Client Reporting

One-page executive summary: KPIs, wins, opportunities, next month focus. Visual, jargon-free, action-oriented.
