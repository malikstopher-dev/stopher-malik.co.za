UI = how it looks. UX = how it works. Both essential. Neither sufficient alone.

## UX: The Invisible Strategy

User research, personas, journeys, flows, wireframes, prototypes, usability testing, information architecture, interaction design, accessibility planning. Success metric: task completion rate, time-to-complete, error rate, satisfaction (SUS/NPS).

## UI: The Visible Craft

Visual design, colour, typography, spacing, iconography, motion, component library, design tokens, dark mode, responsive behaviour, handoff specs. Success metric: visual consistency, brand alignment, developer implementation fidelity, aesthetic-usability effect.

## The Overlap

Design systems live at the intersection. UX defines component behaviour; UI defines component appearance. Prototypes need both. Handoff requires both.

## Common Confusion

"Make it pretty" → UI request. "Users can't find the contact form" → UX problem. "Our bounce rate is 80%" → UX + UI (speed, clarity, trust). "Developers keep guessing spacing" → Design system gap.

## Hiring

UX Designer: research, strategy, flows, testing. UI Designer: visual systems, motion, polish. Product Designer: both (rare, expensive). Agency: usually split or fractional.

## Our Process

Discovery (UX) → Strategy/IA (UX) → Wireframes (UX) → Visual Design (UI) → Design System (both) → Prototype (both) → Usability Test (UX) → Handoff (UI specs) → QA (both).

## Key Insight

Great UX with poor UI = usable but untrustworthy. Great UI with poor UX = beautiful but broken. South African users: trust first (UX), then beauty (UI). Load shedding = speed = UX.

We deliver both: UX strategy in discovery, UI craft in design, unified in our design system.
