A technical audit is the foundation. Fix these before content and links.

## Crawl & Index

Robots.txt: no critical paths blocked. Sitemap.xml: valid, under 50k URLs, auto-updated, submitted. Index coverage: 0 errors, 0 excluded (unless intentional). Noindex: thin pages, admin, search results, thank-you.

## Site Architecture

Depth: max three clicks to any page. Orphan pages: zero. Internal links: three to five per 1000 words. Breadcrumbs + schema. Pagination: rel=next/prev or view-all.

## URL Health

Canonical tags: self-referencing on all indexable pages. No duplicate content. Parameters: handled in GSC or canonicalised. Trailing slash consistency. HTTPS everywhere. No redirect chains (more than one).

## Speed & Core Web Vitals

LCP under 2.5s (mobile). INP under 200ms. CLS under 0.1. TTFB under 600ms. Total page weight under 1MB. Requests under 50. Critical CSS inlined. Unused CSS/JS removed.

## Mobile Usability

Viewport meta. Touch targets 48 by 48px. Font 16px+. No horizontal scroll. Tap targets spaced. No interstitials blocking content.

## Structured Data

Article, Service, Product, FAQ, Breadcrumb, LocalBusiness, Organization, WebSite, VideoObject. JSON-LD. Validated in Rich Results Test. No errors in GSC enhancements.

## Security & Trust

HSTS. CSP (report-only first). No mixed content. Certificate valid + SHA256. Security headers: X-Frame-Options, X-Content-Type-Options, Referrer-Policy.

## International/Local

hreflang if multilingual. LocalBusiness + geo for each location. Service area markup. Currency ZAR. Language en-ZA.

## Monitoring

Weekly: crawl errors, index coverage, Core Web Vitals (CrUX). Monthly: full Screaming Frog/ Sitebulb crawl. Quarterly: competitor technical gap.
