A website isn't a "set and forget" asset. It's living infrastructure that degrades without care.

## Security (Critical)

Core updates (CMS, plugins, theme): weekly. Security patches: within twenty-four hours. SSL renewal: automated. Malware scan: daily. WAF rules: updated. Backup: daily offsite, tested monthly restore.

## Performance (Continuous)

Core Web Vitals: monthly Lighthouse CI. Image optimisation: new uploads auto-WebP. Database cleanup: quarterly. Cache warming: post-deploy. CDN purge: on content change.

## Content & SEO (Monthly)

Broken links: automated weekly scan. Redirect audit: quarterly. Content decay: identify declining pages, update/redirect. Keyword ranking: monthly report. GBP posts: weekly.

## Technical Debt (Quarterly)

Dependency audit: npm audit / composer outdated. Browser support review. Polyfill cleanup. Unused CSS/JS purge. Bundle size analysis.

## Monitoring & Alerts

Uptime: 99.9% target (one-minute checks). Error tracking: Sentry/LogRocket. Performance budgets: LCP under 2.5s, INP under 200ms, CLS under 0.1. Alert: Slack/email/WhatsApp on breach.

## Our Maintenance Tiers

**Essential (R1,500/mo)**: Security updates, backups, uptime monitoring, SSL, monthly report. **Growth (R3,000/mo)**: Essential + performance monitoring, Core Web Vitals, monthly content update, quarterly audit. **Enterprise (R5,000+/mo)**: Growth + priority SLA (two hours), dedicated Slack, custom development hours, staging environment, disaster recovery test.

## Cost of Neglect

Hacked site: R15,000–50,000+ recovery. SEO penalty: six to twelve months recovery. Lost leads: incalculable. Brand damage: permanent.

Maintenance is insurance. The premium is predictable; the claim is catastrophic.
