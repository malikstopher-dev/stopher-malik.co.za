South Africa: 70%+ web traffic is mobile. Desktop-first design is business malpractice.

## Mobile-First ≠ Mobile-Only

Start design at 375px. Enhance progressively for tablet (768px), desktop (1024px+), ultrawide (1440px+). Every feature works on mobile first.

## Touch-First Interactions

• 44×44px minimum tap targets. Thumb-zone navigation (bottom nav bar). Swipe gestures for carousels. No hover-dependent content.

## Performance Budget

• Under 100KB CSS, under 200KB JS (gzipped), under 500KB total page weight. WebP/AVIF images. Lazy load below fold. Critical CSS inlined. Our sites target under 2.5s LCP on 3G.

## Content Prioritisation

Mobile users scan. Above fold: value prop, primary CTA, trust signal. Secondary content in accordions/tabs. No horizontal scrolling.

## Form Optimisation

Native input types (tel, email, number). Autocomplete attributes. Single-column layout. Large fonts (16px minimum prevents iOS zoom). Sticky submit on long forms.

## Testing Reality

Test on: iPhone SE (375px), average Android (360–412px), tablet (768px), desktop (1920px). Real devices, not just DevTools. Test on 3G throttle.

## Progressive Enhancement

CSS Grid/Flexbox for layout. @supports for modern features. Fallbacks for older browsers (rare in SA). No JavaScript dependency for core content.

Every site we build is mobile-first by default — it's not an upsell, it's the baseline.
