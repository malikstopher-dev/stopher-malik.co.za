No black boxes. No guesswork. Four deliberate, transparent stages — each with a tangible deliverable you can review, approve, and build upon.

## Stage 1: Discovery & Strategy (Week 1)

Kickoff workshop (90 min). Business goals, audience, competitors, content audit, technical requirements. Deliverable: **Project Brief** — scope, timeline, tech stack, success metrics, content plan. You approve before we proceed.

## Stage 2: Design & Prototyping (Week 2–3)

IA & sitemap. Wireframes (key pages). Design system (colours, typography, components). High-fidelity mockups (Figma). Interactive prototype. Deliverable: **Design System + Prototype** — clickable, reviewable, testable. Two revision rounds included. You approve before we code.

## Stage 3: Development & QA (Week 3–6)

Next.js + TypeScript + Tailwind. Component library from design system. CMS setup (Contentful/Sanity). Content migration. SEO foundation (schema, sitemap, robots, meta). Cloudflare Pages deploy. BrowserStack testing (15 browsers/devices). Lighthouse CI (every PR). Deliverable: **Staging URL** — fully functional, content-populated, tested. You approve before launch.

## Stage 4: Launch & Hypercare (Week 6–7)

DNS cutover. Cloudflare config (caching, WAF, analytics). GA4/GSC/GBP final config. 30-day hypercare: daily monitoring, priority fixes, content tweaks, training sessions. Deliverable: **Live Site + Documentation** — repo access, CMS guide, analytics dashboard, maintenance plan.

## Post-Launch Options

**Maintenance Retainer**: security, updates, backups, monitoring, SLA. **Content Retainer**: monthly blog, case studies, updates. **Growth Retainer**: SEO, CRO, analytics, quarterly strategy.

## Timeline Guarantee

Fixed timeline in contract. Milestone dates in Project Brief. Buffer built in. If we slip without client-caused delay, we discount 10% per week.

## Transparency Tools

Notion project wiki (live). Figma (design reviews). GitHub (code + issues). Cloudflare (deploy preview URLs). Loom (async walkthroughs). Weekly Loom + bullets. Bi-weekly 30-min sync.

You always know: what's done, what's next, when it's due.
