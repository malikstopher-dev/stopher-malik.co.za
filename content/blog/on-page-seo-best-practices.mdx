On-page SEO is controllable, measurable, and compounds. Here's the checklist we use for every page.

## Title Tag

Primary keyword near start. 50–60 chars. Unique per page. Brand at end: "Primary Keyword | Secondary | SMK Web Design"

## Meta Description

• 150–160 chars. Keyword + benefit + CTA. Unique. Not a ranking factor but drives CTR.

## H1 Structure

One H1 per page. Primary keyword. Matches search intent. Above fold.

## Heading Hierarchy

H2 for main sections. H3 for subsections. Keywords in H2/H3 where natural. No skipped levels.

## URL Structure

Short, descriptive, keyword-rich. /services/web-design-johannesburg/ not /page?id=123. Hyphens, lowercase.

## Image Optimisation

WebP/AVIF. Descriptive filenames (web-design-johannesburg.jpg). Alt text: descriptive + keyword where relevant. Width/height attributes. Lazy load.

## Internal Linking

• Three to five internal links per 1000 words. Descriptive anchor text. Link to pillar pages and conversion pages. No orphan pages.

## Schema Markup

Article, Service, Product, FAQ, Breadcrumb, LocalBusiness. JSON-LD. Test with Rich Results Test.

## Content Quality

• 1500+ words for competitive terms. Original insights. Data/examples. Updated regularly. E-E-A-T signals.

## Core Web Vitals

LCP under 2.5s, INP under 200ms, CLS under 0.1. Monitor in Search Console and CrUX.

## Technical Health

Noindex thin pages. Canonical tags. XML sitemap. Robots.txt. HTTPS. No mixed content. Redirect chains under two.

Every page we build passes this checklist before launch.
