Your website is the primary touchpoint for your brand identity. It needs to reflect your visual language consistently across every page.

## Brand Guidelines as Code

Translate your brand guidelines into CSS custom properties: colours, typography, spacing, component styles. This ensures consistency and makes updates trivial.

## Logo Usage

Primary logo, secondary mark, icon variant. Define clear space, minimum sizes, and forbidden uses. Implement as an SVG component system.

## Colour System

Primary, secondary, accent, semantic (success, warning, error). Define hex, RGB, and CSS variable formats. Test contrast ratios for accessibility.

## Typography Scale

Font families, weights, sizes, line heights. Use a modular scale. Implement with CSS clamp() for fluid responsiveness.

## Component Library

Buttons, forms, cards, navigation — all styled to your brand. Document with Storybook or a living style guide.
