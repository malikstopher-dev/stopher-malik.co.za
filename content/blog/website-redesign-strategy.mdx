Redesign isn't cosmetic — it's strategic. Done wrong, it kills rankings. Done right, it multiplies conversions.

## Red Flags (Time to Redesign)

>3 years old. Mobile usability fails. Core Web Vitals poor. Brand evolved, site didn't. Conversion rate declining. Competitors outrank/outconvert. CMS unsupported/secure. Analytics blind (no events, no funnels). Team can't update content easily.

## SEO-Preserving Redesign Checklist

**Pre-Launch**: Crawl current site (Screaming Frog). Map every URL → new URL. 301 redirect plan (1:1, no chains). Preserve title tags, meta descriptions, headings, schema. Benchmark rankings/traffic for top 50 pages.

**Design & Dev**: Mobile-first. Component library. Design system. Next.js/Static for speed. Schema parity. Content migration (not rewrite — preserve performing copy). Staging environment (noindex).

**Pre-Launch QA**: Lighthouse CI (every PR). Redirect tester (100% 301s). Schema validator. Crawl staging. Accessibility audit. Speed test (3G throttle).

**Launch**: DNS cutover (low TTL). Cloudflare config. GA4/GSC/GBP verify. Monitor: 404s, redirect chains, rankings (daily week 1, weekly month 1).

**Post-Launch (30 Days)**: Daily rank check (top 50). Weekly traffic/conversion audit. Fix 404s immediately. Submit updated sitemap. Disavow toxic links if any.

## Common Disasters

Launch Friday (no weekend support). No redirect map. Rewrite all copy. Change URL structure without 301s. Block staging in robots.txt but forget noindex. Launch before QA.
